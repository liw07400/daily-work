# Contributing

Fork the repository, create a branch from main, edit the matching daily log or project SKILL.md, search for duplicates, and open a PR to main. Include source date, evidence, before → after where relevant, validation, and remaining uncertainty. Direct push access is not implied.

Never upload credentials, cookies, customer personal information, private chat exports, local paths, or unredacted screenshots. Do not claim live success without current evidence. The maintainer reviews and merges contributions.

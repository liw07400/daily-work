---
name: daily-work
description: Maintain evidence-backed daily logs and project skills from accessible work-session records.
---

1. Review accessible same-day conversations, tool outputs and relevant source records; state coverage limits.
2. Search the date file and relevant project Skill. Skip duplicates; record only new facts, evidence or status changes.
3. Separate completed work, plans, failures and unknowns. Include date, object/page, evidence, before → after and status.
4. Put short-term events in YYYY-MM-DD.md and reusable procedures in the matching project SKILL.md.
5. Mark missing proof 待核实. A draft, API acceptance or local test does not prove later external gates.
6. Redact secrets, personal/customer data and local paths; keep raw chat/database/command archives private.
7. Create a dated branch and PR to main; never push directly to main or auto-merge.
